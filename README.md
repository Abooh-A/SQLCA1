# Library Management Database (NCI Group Project, CA1)

A relational database for a library system, designed and built in MySQL as a team project. It covers books, devices, rooms, customers, loans, fines, waitlists and reservations across 25 normalised tables, with analytical queries written by each team member.

## Contents

- `LIBRARY_SQL_CA1.sql`: schema
- `CA1_GroupE_dummydata.sql`: sample data
- `ERD_Miro_CA1_GroupE.pdf` and `CA_GroupE_Model.mwb`: entity relationship diagram and MySQL Workbench model
- `Abooh_Queries.sql`, `Eesha_Queries.sql`, `Julieta_Queries.sql`: analytical queries by each team member

**Tools:** MySQL, MySQL Workbench, Miro, Git
